# sentence-transformers) cannot be installed - for example a corporate network
# that blocks huggingface.co, or a Python build with no torch wheel.

# ONNX build of all-MiniLM-L6-v2 (identical model weights, onnxruntime instead
# of torch). Select it with EMBEDDING_BACKEND=chroma_onnx in your .env.
#
# This is a documented, explicitly opt-in alternative - NOT a silent fallback,
# and NOT the graded default. See README.md -> "Embedding backends".
